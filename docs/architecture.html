03 요청 파이프라인 · POST /api/proxy

ProxyOrchestrator.process() 하나가 전 구간을 동기적으로 처리한다. WebClient 호출은 모두 .block()으로 받고, 처리량은 리액티브 조합이 아니라 가상 스레드에 의존한다. 외부 호출 3개는 직렬이다(형태소 분석과 피벗을 병렬화할 여지는 있으나 하지 않는다). 조건부 표시가 붙은 단계는 티어에 따라 건너뛴다.

ENTRYProxyController
인증된 요청 수신
{ "text": "..." } + @AuthenticationPrincipal에서 memberId 추출
↓
STEP 01 · ROUTINGCostRouter
토큰 계산 → 언어 감지 → 티어 결정
토큰 수가 routing.token-threshold(50) 미만이면 언어 감지도 하지 않고 SKIP. 신뢰도가 0.7 미만이면 오판으로 보고 TIER_1로 폴백. 텍스트는 변형하지 않고 판단만 한다.
↓
SKIP인 경우 02 · 03-B · 03 · 05 전부 우회 → 원문 그대로 STEP 04로 직행

용어집 마스킹

↓
STEP 03-B · MORPHOLOGY TIER_3 & inject-hintFastApiMorphologyClient
형태소 힌트 조회 — 현재 비활성
피벗보다 먼저 호출한다(영어로 바뀐 뒤엔 어근·접사를 찾을 수 없다). 마스킹된 텍스트를 넘기고, 사이드카가 {TERM_x}를 분석 대상에서 제외한다. app.morphology.inject-hint: false라 실측상 역효과(입력 +162 토큰, 답변에 접사 노출)를 근거로 호출 자체를 생략한다.

원어 → 영어 피벗

↓
STEP 04 · LLMSystemPromptBuilder → OpenAiLlmClient
시스템 프롬프트 조립 + 추론 1회
치환된 토큰이 없고 지시할 내용도 없으면 빌더가 빈 문자열을 반환하고 system 메시지를 생략한다. 지킬 게 없는데 지시를 붙이면 입력 토큰만 늘어 절감 목적에 역행하기 때문이다. 과금용 sentTextToLlm에는 시스템 프롬프트를 포함한다(프록시가 얹은 비용도 지표에 남긴다).

↓

04 라우팅 티어 매트릭스

분기 조건은 전부 RoutingTier enum의 플래그에 들어 있다. 오케스트레이터에는 언어 이름이 등장하지 않는다. 매핑에 없는 언어는 가장 안전한 TIER_1로 떨어진다.

티어진입 조건마스킹형태소피벗재번역외부 호출
SKIP 토큰 < 50 (언어 감지 안 함) ———— OpenAI 1회
TIER_1 en · 또는 신뢰도 < 0.7 폴백 ✓——— OpenAI 1회
TIER_2 vi 베트남어 — 비용 문제 ✓—✓✓ DeepL 2회 + OpenAI 1회
TIER_3 tl 타갈로그 — 비용 + 이해력 문제 ✓off✓✓ DeepL 2회 + OpenAI 1회 (+사이드카 1회, 비활성)

05 인증 흐름 · 카카오 OAuth2

세션 기반이다. JWT는 없다. /login과 /css/**만 공개고 나머지 전부 authenticated() — /api/**도 포함된다.

1
브라우저가 GET /login → Thymeleaf 로그인 페이지 PageController
2
카카오 인가 요청 → 콜백 /login/oauth2/code/kakao
3
Spring Security가 토큰 교환 후 사용자 정보 조회 kapi.kakao.com/v2/user/me
4
CustomOAuth2UserService가 (kakao, providerId)로 Member를 upsert nativeLang = "ko"
5
속성 맵을 복사해 memberId를 주입한 DefaultOAuth2User 반환 모든 컨트롤러가 이 값으로 DB 식별자를 얻는다
6
세션 발급 → defaultSuccessUrl("/"). 이후 요청은 JSESSIONID로 인증 로그아웃 시 세션 무효화 + 쿠키 삭제

07 알려진 공백 · 다이어그램에 없는 것

아직 구현되지 않았거나 의도적으로 꺼둔 지점. 위 그림에 컴포넌트로 그리지 않은 이유가 여기 있다.

형태소 힌트 주입 (의도적 비활성)
사이드카·클라이언트·프롬프트 조립까지 다 있으나 inject-hint: false로 실행 경로에서 빠져 있다. 근거는 docs/pipeline-measurement.md.
실패 이력 적재 경로 없음
ProxyRequestStatus.FAILED는 선언만 되어 있고 기록되지 않는다. UsageRecorder는 SUCCESS를 하드코딩하고, 실패는 저장 전에 던져진다.
외부 API 예외 전용 핸들러 없음
GlobalExceptionHandler에 ExternalApiException 처리가 없어 DeepL/OpenAI 실패가 일반 500으로 나간다.
API 인증 실패 응답이 HTML
/api/** 전용 AuthenticationEntryPoint가 없어 미인증 API 호출이 401 JSON 대신 로그인 페이지로 리다이렉트된다. CSRF는 임시 비활성 상태.
마스킹 토큰의 번역 보호 미완
TranslationRequest.preserveMaskedTokens가 설정되지 않아 DeepL tag_handling으로 {TERM_x}를 보호하는 규약이 끝까지 연결되지 않았다(TranslationRequest.java TODO).
요청 본문 검증 없음
ProxyRequestDto에 @NotBlank가 없다. 빈 텍스트는 LlmRequest.of에서 터져 400으로 나간다.
비동기 · 캐시 · 스케줄링 미사용
AsyncConfig는 @EnableAsync만 있고 @Async 사용처가 없다. @Scheduled/@Cacheable도 없다.
스키마 마이그레이션 도구 없음
운영에서도 ddl-auto: update로 스키마가 배포와 함께 자동 반영된다. Flyway 도입 전까지는 되돌릴 수 없는 변경에 주의가 필요하다.
TIER_3 재번역 대상 언어
재번역이 DeepL에 TL을 대상으로 요청한다. DeepL 지원 대상 언어 목록에 타갈로그가 없어 이 구간이 런타임에 실패할 수 있다. 코드에 예외 처리는 없다.
