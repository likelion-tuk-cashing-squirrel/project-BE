02

단계별 증명 수단

"된다"가 아니라 "이 값이 이렇게 찍힌다"로 보여줄 대상. 촬영할 때 이 순서대로 화면을 띄운다.

단계판단 근거화면에 띄울 증거어디서
STEP 01
CostRouter		 토큰 수 · 감지 신뢰도임계치 50 / 0.7과 비교 라우팅 결정: tier=TIER_3, language=tl, tokens=126, confidence=… 콘솔 DEBUG
STEP 02
TermMasker		 용어집 길이 내림차순SOP1이 SOP보다 먼저 매칭 치환 전/후 문자열 + dictionary.size(), 조회 SQL 콘솔 show-sql
STEP 03-B
사이드카		 접사 분해어근 + 접사 + 상(aspect) POST /morphology/hints 응답 JSON curl
STEP 03
피벗		 영어 토큰이 더 싸다같은 뜻 en 10 / vi 14 / tl 20 OpenAI로 실제 나가는 요청 본문 요청 로그
STEP 04
LLM		 공급자 실측 사용량추정치 아님 응답의 usage.prompt_tokens / completion_tokens 응답 JSON
STEP 05
TermRestorer		 사전 역치환토큰 → translation 복원 전/후 diff, 남은 {TERM_ 개수 0 콘솔
STEP 06
CostCalculator		 단가 × 절감 토큰입력·출력 단가 분리 비용 계산 완료: … savedUsd=0.000995 + usage_log INSERT 콘솔 + DB
결과
UI		 같은 값이 화면에로그와 UI 숫자 일치 답변 아래 절감 배지 → 펼치면 입력·출력 내역 브라우저
